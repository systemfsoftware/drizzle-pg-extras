Renamed from `@systemfsoftware/drizzle-pg-extras` to `@systemfsoftware/timescale-drizzle`, to match the repository. Install and import the new name; the old package gets no further releases.

- The command is `timescale-drizzle generate` and `timescale-drizzle check`.
- Generated migration files say `-- Generated by timescale-drizzle` in their header.
- Partition conversion errors start with `timescale-drizzle:`.

The API names (`defineExtras`, `PgExtras`, `PgExtrasError`) and the `_pg-extras.json` snapshot file are unchanged.
